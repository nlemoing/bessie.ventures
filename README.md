## Generating title.svg
1. In GIMP, create a new canvas with width 2000 and height 1000 (must match viewbox). Optionally, load the existing SVG as another layer to make sure the title is included.
2. Create some text and position it in the middle of the screen
3. On the right hand side, under Layers, right click the layer and click "Text to Path"
4. On the right hand side, under Paths, right click the newly created path and export it to title.svg
